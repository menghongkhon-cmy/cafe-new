# ☕ HONG Coffee — Modern Coffee Shop Website

A complete, modern, beautiful, and fully responsive multi-page web application for **HONG Coffee**, a premium café in Phnom Penh, Cambodia.

## 🌟 Brand Guidelines
- **Tagline:** “Brewed with Passion, Served with Love.”
- **Color Palette:** Warm Coffee Brown, Cream/Beige, Dark Brown, and Gold Accents (`#e2bc49`).
- **Typography:** Playfair Display (Serif) & Poppins (Sans-Serif).
